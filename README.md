# 📚 Study Planner App

Aplikasi Study Planner pribadi yang dibangun menggunakan framework Flutter untuk mengelola jadwal belajar, tugas, dan aktivitas harian.

---

## 🛠️ Tech Stack & Dependensi Utama

Berikut adalah package/library utama yang digunakan dalam proyek ini:

- **Flutter SDK**: `>=3.0.0`
- **[provider](https://pub.dev/packages/provider)**: Management state lokal aplikasi
- **[go_router](https://pub.dev/packages/go_router)**: Manajemen navigasi dan routing

> *Daftar lengkap versi package yang ter-install dapat dilihat pada file `pubspec.lock` atau `package_version.txt`.*

---

Ikuti langkah-langkah berikut untuk menjalankan aplikasi di mesin lokal Anda:

- Flutter SDK sudah terinstal (`flutter doctor`).
- Emulator (Android/iOS) atau Perangkat Fisik terhubung.
